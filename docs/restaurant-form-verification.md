# Add/Edit and photo verification — October 10, 2026

The shared native form now implements Add Restaurant and Edit Restaurant. Add starts empty and unrated; Edit starts with the selected record. Save validates the required name and any supplied phone numbers, adds or updates the same complete record, and returns to List or Details. Back discards the draft. Drafts and saved records survive saved-state restoration; this remains session data rather than durable storage.

## Photo fixes

The picker disables Save until the selected photo decodes successfully, displays distinct loading/unavailable feedback and supports reselection. A readable temporary grant is valid for the session; inability to persist that grant does not automatically reject the image. Missing/revoked images remain a visible unavailable state. Image decoding remains bounded and off the main thread, with orientation handling.

Gallery titles now follow the selected seeded photo: **Chicken shawarma plate**, **Falafel plate**, **Baklava**. It displays **n / total · My photos** and **Use arrows or choose a photo** above the thumbnails. Long captions can scroll completely. Cover URI takes precedence over an old bundled resource. Adding a photo normalizes legacy caption alignment so its caption cannot attach to an older image accidentally.
