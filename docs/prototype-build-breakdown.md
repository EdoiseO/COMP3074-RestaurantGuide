## Supporting components from the current wireframe

Build these once and reuse them across the sections:

- **Restaurant card:** image, name, summary and rating; light grey/lavender 1px outline and 24px corners.
- **Tags:** selectable chips on Restaurant List; read-only labels on Restaurant Details; editable/addable/removable tags in Add/Edit. Use the current Shawarma, Turkish and Mexican sample categories. Match any selected category, as in the current demo; record this behavior in the implementation decisions.
- **Form fields and buttons:** shared Add/Edit preserves existing wording, purple styling, 12dp input corners, floating labels and the explicit 16dp photo-strip-to-Description border gap. Native address-details assistance, postal-code formatting and multiple-phone controls extend the saved form.
- **Rating picker:** drag directly across enlarged stars in half-star increments, with the exact guidance “Slide your finger across the stars.”, a numeric value and Save/Cancel. The user's explicit request authorizes fractional ratings; the model now uses `Float` and versioned UI state restores earlier integer snapshots. This is a native implementation, separate from Figma's fixed illustration and the unchanged integer FR-07 text.
- **Photos:** My photos follows tags and precedes address on Details; in Add/Edit it follows the required name and precedes Description. The form replaces/removes the cover and adds/removes album photos, with optional caption editing for chosen photos. The dark gallery includes title/count, Close, swiping, previous/next, thumbnail selection and 100–300% zoom through pinch or −/percentage/+ controls. A single finger swipes at fit and pans within the enlarged image; arrows/thumbnails reset the selected image to fit. Loading/unavailable photos disable zoom, and long captions remain scrollable. The actual Android picker round trip passed returned-image byte-identity, caption Save and restoration checks; durable photo storage remains separate work.
- **Visit notes:** quick edit from the Notes pencil saves/cancels a session draft. The shared Add/Edit form also includes Visit notes. Notes describe the restaurant visit; a caption belongs to one image.
- **Map/email actions:** compact purple buttons below the embedded map and above Notes. View full map opens the selected static preview with Back and Get directions. Email attempts an email-app draft containing name, address, phone number(s), rating, tags and description, with a copyable fallback when no email app is available. Selected-record map navigation, directions URL and email intent/fallback passed device checks; external email composition remains unverified.

Photos, captions, visit notes and half-star dragging are explicitly authorized user additions, now included in the prototype model. They do not silently revise the original proposal/FR text. Durable persistence remains separate work.
