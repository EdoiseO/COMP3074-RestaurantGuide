Restaurant Guide keeps restaurant information, ratings, photos and visit notes together, helping you remember what you ate and whether you would order it again. The purple Splash Screen introduces the application.

The Restaurant List uses scrollable cards with a photo, name and rating. Rounded corners, soft borders and purple headings make the saved restaurants easy to scan.

Search restaurants updates results as you type. Select multiple tags, or All to reset them. No restaurants found provides a way to clear the search and filters.

Restaurant Details shows the selected cover, rating, description, read-only tags, photos and contact information. Back returns to the list while preserving search and selected filters.

My photos opens a larger gallery with captions, swiping, arrows and thumbnails. Zoom allows closer inspection. Each caption describes one photo; visit notes describe the restaurant visit.

Edit visit notes opens a draft for the selected restaurant. Cancel discards it, and Save applies it. The rounded lavender Notes panel keeps the saved note readable.

View full map shows the selected static Map preview and saved address. Back returns to Details; Get directions prepares an external destination URL. Live location remains future work.

Share by email prepares name, address, phone numbers, rating, tags and description. Without an email app, Email app unavailable shows a copyable fallback containing the restaurant details.

Add restaurant reuses rounded fields and clear labels. Saving without a name displays Restaurant name required. After Got it, enter the name and other details.

Slide across enlarged stars in half-star steps. Rating Cancel discards the selection; rating Save updates the draft. Add tag creates a custom tag before the full form is saved.

Edit pre-fills the saved record. Back discards changes; Save updates it. Delete asks for confirmation: Cancel keeps the record, while Delete removes it from the current session.

About identifies Restaurant Guide, COMP3074, Team P12 and all four team members. This interactive UI prototype uses session data. Permanent storage, live maps and location permissions remain future work.
